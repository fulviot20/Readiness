# Readiness – roadmap

Obiettivo di lungo periodo: un'app completa per l'atleta endurance, alternativa a Bevel / Whoop / Fitbit su Android.
Si procede un punto alla volta; quando uno è fatto si spunta.

## Funzioni che mancano rispetto a Bevel, Whoop e Fitbit
- [ ] 1. Diario delle abitudini con correlazioni (alcol, caffè tardi, cena pesante, schermi a letto, stress…): dopo qualche settimana l'app mostra quanto ciascuna pesa su recupero e sonno
- [ ] 2. Coach del sonno: debito di sonno nel tempo, regolarità degli orari, grafico delle fasi lungo la notte
- [ ] 3. Grafici della giornata: frequenza cardiaca, stress e "riserva di energia" ora per ora
- [ ] 4. Report mensili e trend lunghi, spiegati a parole
- [ ] 5. Riquadro Calories di Today che apre direttamente il diario alimentare
- [ ] 6. Validazione dello score (periodo di test in corso da novembre 2026)

## Verso un prodotto condivisibile
- [ ] 7. Codice più ordinato: dividere il file unico dell'app in moduli, test automatici
- [ ] 8. Server vero e account (multiutente), senza dipendere da GitHub Actions / ntfy
- [ ] 9. App nativa Android e widget per la schermata Home
